# Gestión de Biblioteca — Módulo de Libros

Sistema para registrar, consultar, modificar y eliminar libros de una biblioteca.

## Flujo de trabajo con ramas
- **main**: versión estable y funcional.
- **feature/nombre-cambio**: cada modificación se hace en una rama separada.
- Al terminar se abre un Pull Request hacia main para revisar y fusionar.
